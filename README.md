# Clover Tracker — Stage 1

Mobile-first React + TypeScript foundation for Clover Tracker.

## Run

```bash
npm install
npm run dev
```

Then open the local Vite URL shown in the terminal.

## Build check

```bash
npm run build
```

## Stage 1 scope

- Production-oriented project foundation
- Strict TypeScript
- iOS-inspired mobile shell
- Bottom tab navigation
- Initial Home screen
- Design tokens and responsive styling
- Core domain types
- Storage, food database, AI recognition and nutrition calculation interfaces
- Zustand state foundation

The remaining product modules are intentionally staged for subsequent phases.
